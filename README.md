# 🌐 Port Scanner

A Python-based port scanner built as part of my cybersecurity learning journey.

## Features
- Scans a range of TCP ports on any target
- Identifies open ports and their services
- Displays scan time and resolved IP

## Usage
python3 port_scanner.py

## Concepts Learned
- Python socket programming
- TCP/IP and port concepts
- Network reconnaissance basics

## ⚠️ Legal Notice
Only use on systems you own or have permission to scan.
